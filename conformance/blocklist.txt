# What Test262 covers that client script has not got.
#
# Each line is a path prefix under Test262's `test/`, then two or more spaces,
# then why the language does not reach there. A blocked prefix is not copied
# into `cases/` at all: this file is the record of the gap, so carrying two
# hundred megabytes of tests nobody runs would say the same thing at a cost.
#
# Hand-written, deliberately, and not derived from the schema — one list to
# read beats two that have to agree. Two checks keep it from drifting into
# decoration: `pnpm curate` fails on a prefix that matches nothing upstream, so
# a gap that closes shows up as a stale line rather than as silence; and
# `pnpm test` fails if anything under `cases/` is blocked, so a line added
# without re-copying cannot quietly contradict the corpus.
#
# A file that is neither blocked nor copied is one V8 itself does not pass;
# `pnpm curate` prints those with the error each produced.
#
# Blank lines and `#` lines are ignored.

# ── whole suites ────────────────────────────────────────────────────────────

intl402/                            ECMA-402: there is no `Intl`, and locale data is a host's, not a language's
